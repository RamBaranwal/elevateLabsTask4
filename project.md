# DevOps Project Documentation

## Project Overview

This project demonstrates a Git-based DevOps workflow.

## Workflow

1. Create a main branch.
2. Create a development branch.
3. Create feature branches.
4. Make changes in feature branches.
5. Push feature branches to GitHub.
6. Create Pull Requests.
7. Merge feature branches into dev.
8. Merge dev into main.
9. Create a Git tag for the final version.

## Git Best Practices

- Write meaningful commit messages.
- Use feature branches for development.
- Review changes using Pull Requests.
- Keep the main branch stable.
